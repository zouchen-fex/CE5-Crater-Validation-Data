# Apollo 16 ArcMap data

Download all three ZIP archives in this folder and extract them into the same parent directory, merging the Apollo16_ArcMap folders. Then open Apollo16_marked_cases.mxd in ArcMap 10.8.

Use Apollo16_catalog_comparison_80pct.mxd for the uniform 80% footprint catalog comparison.

See README.md and README_zh-CN.md for full instructions, profile extraction, data provenance and evaluation rules.
