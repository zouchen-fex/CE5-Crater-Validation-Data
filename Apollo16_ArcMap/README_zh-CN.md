# Apollo 16 ArcMap 工程使用说明

## 下载后直接打开

1. 下载全部三个压缩包：`Apollo16_project_and_profiles_20261125.zip`、`Apollo16_Liu_reference_20261125.zip`、`Apollo16_other_reference_layers_20261125.zip`。将三者分别解压到同一个上级目录，允许合并同名的 `Apollo16_ArcMap` 文件夹。三个包内文件互不重复，合并后才是完整工程。不要在压缩包内双击工程，不要只拷贝 `.mxd`。
2. 使用 ArcMap 10.8 打开解压目录中的工程。所有数据源已改为相对路径，整个 `Apollo16_ArcMap` 文件夹可以一起移动。其他 ArcMap 版本尚未测试。
3. 查找带编号案例，打开 `Apollo16_marked_cases.mxd`；查看 80% 面积保留规则下的比较，打开 `Apollo16_catalog_comparison_80pct.mxd`；查看原始未标记背景及原先隐藏的目录，打开 `Apollo16_original_context.mxd`。

标记版和原始背景版保留原来的历史图层（52 TP、60 FP、31 FN），并未悄悄替换其内容。正式的 80% 规则版本为 52 TP、57 FP、30 FN，预测 109 个、参考 82 个。标记版黄色图层包含较大搜索区内的 244 个预测，并不等于上述 109 个评估预测。请按目的选择工程。

## 高程剖面

1. 在标记工程或 `images/case_locations_annotated.png` 中找到案例。数据视图用于导航、查询和新建剖面；布局视图保留作者的编号及剖线示意。
2. 需要米单位高程时，添加 `data/rasters/Apollo16_elevation_m.tif`，或在 80% 工程中选择默认隐藏的 `Elevation_m_for_profiles` 图层。原始编码 DEM 的缩放因子为 0.5；米单位版本已经完成一次换算，不能再乘 0.5。提供的原始剖面截图保留原样，其纵轴数值并未重新计算。
3. 具有 3D Analyst 许可时，启用该扩展和工具条，选择米单位 DEM 作为 Surface，以 Interpolate Line（插值线）绘制穿过目标的线，再使用 Profile Graph（剖面图）。按南北、东西及两条对角线重复提取。仅打开工程和查看 PNG 不需要 3D Analyst。
4. 工程中的黑线、编号和截图属于示意与观察记录，不会自动成为高程表。需要重新绘制剖线或建立线要素来提取新剖面；新的取样位置、插值方式不同，曲线可能与截图略有区别。
5. 综合判断中心凹陷、两侧地形起伏、不同方向的连续性、背景坡度及邻近结构。不能仅凭一个方向的凹陷，或一个方向未呈现完整凹陷，就直接完成身份判定。

## 数据与图件

`data/rasters` 含原始 DEM、米单位 DEM 和已从本机默认地理数据库中导出的山体阴影；不再需要作者电脑上的 Default1.gdb。`data/catalogs` 保留工程引用的 Liu、Wang、Zhang 三个独立目录图层；`data/detections` 是原始直径过滤后的识别结果；`data/catalog_comparison_80pct` 是 80% 面积规则下的图层、匹配表和边界审计；`data/profile_review` 是作者剖面复核的独立观察记录。

`images` 含 Craters 1–14、四张重叠案例、位置总览和工程预览。案例 1–6 对应获得剖面支持的未匹配预测；7–10 对应未匹配参考目标；11–14 对应仍有判定歧义的候选。图中案例编号并非当然等于属性表 ID，尚未提供全部案例与唯一记录 ID 的对照，需结合标记图定位。Crater 13、14 左下角的编号已纠正，其余像素未变。

所有同名 SHP 配套文件必须一起保留。投影是月球等距圆柱，半径 1,737,400 m，中央经线和标准纬线为 0°，单位米，不是地球 WGS84。目录来源、引用信息、坐标细节和故障排查见英文 README。

## 指标口径

预测及参考都要求完整坑面至少 80% 面积落在同一评估范围内，直径 350–1817.4 m；IoU 使用未裁切完整坑面，严格大于 0.4，再按 IoU 从高到低进行一对一匹配。P/R/F1 分别为 47.71% / 63.41% / 54.45%。

另有 36 个未匹配预测获得作者剖面观察支持。52+36=88，占 109 个预测的 80.73%，这是“目录匹配或剖面支持”的比例，不是独立验证的新精确率。历史文件名中的 TP/rejected 只对应当时保存的选择集；四个参考目标在当前 DEM 剖面支持不足，不等于已经证明原目录错误。保留有歧义目标和原始观察，便于使用者独立判读。

本包不含审稿回复、论文、登录信息或识别算法源代码，也不含 NAC 影像拼接底图；地图背景是 SLDEM2015 及其山体阴影。复用第三方目录需引用原始作者并遵循各自的数据条款。
